# Estrutura de conteúdos

Cada lote fica em uma subpasta nomeada lote-AAAA-MM-DD-a-AAAA-MM-DD. Cada peça tem seu próprio arquivo SG-XXX.md. É proibido agrupar roteiros, carrosséis, posts ou Stories em arquivos diários, por tema ou por faixa de IDs. Um ID corresponde a uma única peça e um único Markdown. A pasta do lote pode conter README/índice e documentos auxiliares, sem substituir os arquivos individuais. IDs são globais e sequenciais. Atualizar CALENDARIO.md e conferir a árvore do GitHub antes de declarar conclusão.
