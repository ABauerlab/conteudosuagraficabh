## Regras
- Não sobrescrever, recomprimir ou editar os arquivos originais.
- Manter um arquivo por ID e usar MP4 sempre que possível.
- Vídeos grandes devem ser enviados usando **Git LFS** (configurar rastreamento de `*.mp4`), não como blobs Git comuns. O GitHub bloqueia arquivos comuns acima de 100 MB e recomenda evitar arquivos grandes no histórico.
- Se o ambiente de execução não baixar arquivos Git LFS automaticamente, registrar a limitação e pedir acesso ao arquivo LFS; não fingir que o vídeo foi recebido.
- Não colocar tokens, credenciais ou arquivos pessoais nesta pasta.

O prompt de execução da Etapa 1 deve procurar primeiro os arquivos nesta pasta. O Google Drive continua como cópia de origem/backup.
