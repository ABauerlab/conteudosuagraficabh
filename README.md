# SUA GRÁFICA BH | Máquina de Conteúdo

Repositório oficial e fonte única de verdade para estratégia, pesquisa, roteiros, referências, edição e aprendizado dos conteúdos da SUA GRÁFICA BH.

O sistema foi desenhado para produzir vídeos curtos em escala, com baixa carga operacional para o responsável: a IA pesquisa e roteiriza, João grava no Edits, Claude edita e o Postiz distribui.

## Regra de entrada
Antes de qualquer tarefa, leia [AGENTS.md](AGENTS.md). ChatGPT também deve seguir [CHATGPT.md](CHATGPT.md); Claude Code deve seguir [CLAUDE.md](CLAUDE.md).

## Fluxo operacional
1. Pesquisar uma oportunidade.
2. Localizar e verificar a referência original, quando o formato depender de vídeo externo.
3. Criar um roteiro natural com gancho forte.
4. João grava no Edits e envia o arquivo bruto.
5. Claude edita, cria motions e exporta.
6. Postiz distribui para Instagram, Facebook e Threads.
7. Resultados são registrados e usados para orientar novos testes.

## Regra especial para vídeos de reação
O roteiro final para teleprompter só deve ser entregue depois de localizar e verificar o vídeo de referência. Preferir o link direto do Instagram quando a publicação original estiver no Instagram. Não inventar links, não chamar repost de original e não presumir permissão de uso.

## Regras permanentes
- Vender sem parecer publicidade: entreter, informar, surpreender e criar identificação antes de converter.
- Priorizar aquisição de clientes, não visualizações vazias.
- Variar temas, formatos e ganchos.
- Não inventar informações comerciais.
- Respeitar direitos de terceiros e créditos.
- Não prometer viralização; trabalhar com hipóteses e testes.
- Registrar decisões permanentes e aprendizados neste repositório.
