# SUA GRÁFICA BH | Central de Conteúdo

Repositório oficial para organizar estratégia, direcionamentos, roteiros, referências e produção de conteúdo da SUA GRÁFICA BH.

Este repositório é a **fonte única de verdade** para qualquer pessoa ou assistente de IA que trabalhe nos conteúdos da marca, incluindo ChatGPT e Claude.

## Como começar

1. Leia [AGENTS.md](AGENTS.md) antes de qualquer tarefa.
2. No ChatGPT, siga também [CHATGPT.md](CHATGPT.md).
3. No Claude Code, siga também [CLAUDE.md](CLAUDE.md).
4. Leia [DIRETRIZES.md](DIRETRIZES.md) antes de criar ou alterar conteúdo.
5. Consulte [ESTRATEGIA.md](ESTRATEGIA.md) para entender o posicionamento editorial.
6. Siga [PRODUCAO-DE-VIDEOS.md](PRODUCAO-DE-VIDEOS.md) ao escrever roteiros.
7. Cadastre cada conteúdo em [conteudos/](conteudos/), usando o modelo em [templates/ROTEIRO.md](templates/ROTEIRO.md).
8. Registre fontes e links de vídeos originais em [REFERENCIAS.md](REFERENCIAS.md).

## Regra de colaboração entre IAs

- Sempre ler os documentos-base antes de produzir.
- Alterar os arquivos do repositório quando uma decisão virar diretriz permanente.
- Não manter regras importantes exclusivamente na conversa.
- Não inventar produtos, preços, prazos, condições comerciais ou diferenciais.
- Preservar o histórico do Git e registrar alterações com commits claros.
